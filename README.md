# interview-bagu · 八股面试 Skill

计算机领域技术面试「八股」问答与知识沉淀的 QoderWork Agent Skill。

## 它做什么

把「面试八股问答 → 追问 → 沉淀成文档」这个循环标准化：

- **自适应回答**：按问题复杂度分轻/中/重三档，简单术语不啰嗦，系统设计给足深度
- **固定骨架**：每个回答都以「一句话核心」开头、「面试总结」兜底，方便背记
- **知识沉淀**：按主题自动追加到 `~/Documents/秋招:实习/07_八股/` 下的 `.md` 文件
- **复习模式**：随机抽题、主题检索、薄弱点标记，文档不只是"写了就完"

## 目录结构

```
interview-bagu/
├── SKILL.md                 # 主文件：回答骨架 + 沉淀规则 + 工作流
├── references/
│   ├── topics.md            # 主题文件分类清单 + 归属判断规则
│   └── examples.md          # 三档回答 + 追问合并 + 沉淀全流程示例
└── scripts/
    └── append.sh            # 路径处理 + Q序号递增 + 智能插入的追加脚本
```

## 安装

把整个目录放进 `~/.qoderwork/skills/interview-bagu/` 即可被 QoderWork 自动识别。

```bash
cp -r interview-bagu ~/.qoderwork/skills/
```

## 触发方式

在 QoderWork 里直接说：

- `帮我问个八股：Workflow 和 Agent 有什么区别`
- `ReAct 里的 observe 是啥`（追问）
- `追加到八股文档` / `整理一下记录`
- `复习八股，抽我一题`

## 设计由来

沉淀自真实面试准备对话中反复出现的行为模式：先要一句话总结、术语要落到代码、偏好类比与表格对比、反感术语堆叠。这个 skill 把这些隐性偏好显性化成了固定规范。
