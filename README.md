# interview-bagu · 八股面试 Skill (v2.0)

计算机领域技术面试「八股」问答与知识沉淀的 QoderWork Agent Skill。

## 它做什么

把「面试八股问答 → 追问 → 沉淀成文档 → 复习」这个循环标准化：

- **四档自适应回答**：轻档（术语）/ 中档（对比）/ 重档（系统设计）/ **校准档（项目相关，先查代码）**
- **固定骨架**：每个回答都以「一句话核心」开头、「面试总结」兜底，方便背记
- **层级沉淀**：按"主题→小节"归档到 `~/Documents/秋招:实习/07_八股/` 下的 `.md` 文件（v2 起废弃平铺 Q 编号）
- **结构体检**：定期梳理追问关系、合并冗余、拆分过大主题
- **复习模式**：按小节随机抽题、主题检索、薄弱点标记

## v2 相比 v1 的关键升级

| 维度 | v1 | v2 |
|---|---|---|
| 回答档位 | 3 档（轻/中/重） | 4 档（新增**校准档**：涉及用户项目必须先派 Explore agent 查代码） |
| 文档编号 | 平铺 Q1/Q2/Q3… | 层级"主题 N → N.1/N.2"（追问自动归小节） |
| 追加脚本 | 单一模式，`grep -oP`（macOS 崩） | 三模式（append/`--next`/`--list`），awk 兼容 macOS，stdin 输入 |
| 结构维护 | 无 | 新增**结构体检模式**：触发词、分析框架、重构方案输出 |
| 血泪坑清单 | 3 条 | 6 条（新增 heredoc+Python+代码围栏套娃、macOS grep、路径含冒号等） |
| 备份机制 | 无 | 自动备份到 `~/.qoderwork/backup/interview-bagu/`，跨 session 保留 |

## 触发方式

在 QoderWork 里直接说：

**问答类：**
- `帮我问个八股：Workflow 和 Agent 有什么区别`
- `ReAct 里的 observe 是啥`（追问）
- `为什么这么设计` / `举个例子` / `有什么坑`

**沉淀类：**
- `追加到八股文档` / `整理一下记录` / `综上分析写入文档`

**结构类（v2 新增）：**
- `看看现在的组织是否合理` / `有没有可以合并的`
- `感觉 XX 是 YY 的追问` / `结构是不是乱了`

**复习类：**
- `复习八股，抽我一题` / `帮我回顾 RAG 相关`

**项目类（v2 新增，触发校准档）：**
- `我的项目里 XX 是怎么实现的` / `帮我核对一下 hit@3 数据`
- 提到具体路径或具体数字（延迟、准确率、文档数）时自动触发

## 设计由来

沉淀自真实面试准备对话中反复出现的行为模式：先要一句话总结、术语要落到代码、偏好类比与表格对比、反感术语堆叠。**v2 特别加入"项目校准档"** —— 因为在实际对话里出现过 agent 基于用户口头描述推理答案，结果和用户实际代码对不上（如"25 篇文档 vs 实际 24 篇"、"hit@3=0.925 vs 最新 0.9896"），面试被追问细节时会当场翻车。
